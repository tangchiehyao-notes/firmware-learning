# Mini Project

這一頁先回答：

> 如果要把這個網站當成作品集，哪一種小專案最能證明自己真的會？

## 第一版方向

- 選一條 architecture path
- 選一個 component 組合
- 把 build、trace、debug 練習串起來
- 最後整理成可以拿去面試講解的故事

## 候選題目

- trace 一條 MCTP -> PLDM request path
- 做一個 OpenBMC component dependency map
- 從 boot log 到 service ready 建立 bring-up checklist
