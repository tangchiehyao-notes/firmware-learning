# Labs

這個區塊的目的，是把理解轉成可操作的能力。

## 第一版路徑

| 子主題 | 這一頁要回答的核心問題 |
| --- | --- |
| Build | 要怎麼把 source、dependency、image 與 artifact 串起來？ |
| Trace | 要怎麼追一條 request 或 event 的完整資料流？ |
| Debug | 發生 timeout、missing message、missing state 時怎麼切層？ |
| Mini Project | 怎麼把 architecture + components + labs 組成一個作品集題目？ |

## 練習原則

- 不是只看理論，要能自己操作
- 不是只記 command，要知道每個 command 在縮小哪個範圍
- 不是單點練習，要能回扣 architecture 與 component mapping
