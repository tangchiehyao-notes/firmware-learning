# Interview

這個區塊不是背題庫，而是確認你是否真的能把前面三個區塊講清楚。

## 第一版四個方向

| 子主題 | 要檢查的能力 |
| --- | --- |
| Explain | 能不能用 1 到 3 分鐘說清楚一個主題 |
| Draw | 能不能畫出 layer、data flow、component relationship |
| Code Reading | 能不能從問題走到 repo、entry point 與關鍵型別 |
| Debug Questions | 能不能把現象拆成分層排查步驟 |

## 使用方式

- 先從 Architecture 或 Components 選一個主題
- 用 Explain 重講一次
- 再用 Draw 畫一次
- 最後用 Debug Questions 驗證是否真的懂
